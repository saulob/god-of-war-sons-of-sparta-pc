Third-party material of the launcher in God of War: Sons of Sparta PC. The port's own code is GPL-2.0-or-later; its
source code is at https://github.com/saulob/god-of-war-sons-of-sparta-pc. The video core lineage is listed in
gpu/VENDOR.txt of the source.

This file covers what the launcher compiles in or draws: its libraries, its page icons and its sponsor heart.

========================================================================
Application icon: Game Console Ecommerce
========================================================================

Source: SVG Repo (www.svgrepo.com). The file's own header reads "Uploaded to: SVG Repo, www.svgrepo.com, Generator:
SVG Repo Mixer Tools". The source file was named game-console-ecommerce-svgrepo-com.svg.
Modified to use the launcher accent and action edge colors (shape unchanged): the fills rgb(144,224,239) and
rgb(25,144,167) became #DEA959 and #A82C26. packaging/icons/app-icon.svg is the only copy kept.
The ICO and PNG icon files are renderings of the modified SVG (tools/make-app-icon.py).

License: CC0 (public domain dedication), as svgrepo.com/svg/425126, collection "Ecommerce Duotone Filled Icons".


========================================================================
Launcher icon: Heart
========================================================================

Heart icon
Source: SVG Repo (www.svgrepo.com), https://www.svgrepo.com/svg/532473/heart
The file's own header reads "Uploaded to: SVG Repo, www.svgrepo.com, Generator: SVG Repo Mixer Tools". The source
file was named heart-svgrepo-com.svg.
Modified to be a white filled heart: the stroke color #000000 became #FFFFFF and a #FFFFFF fill was added (the path is
unchanged). assets/launcher/sponsor-heart.svg is the only copy kept; assets/launcher/sponsor-heart.png is a 64 x 64
rendering of it.

License: CC0 (public domain dedication).
