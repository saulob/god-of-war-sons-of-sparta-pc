# God of War: Sons of Sparta PC v@VERSION@

Native PC port of *God of War: Sons of Sparta* (`CUSA57767` **1.00 USA** and **1.01 USA**).

**No original game files are included.** Supply your own legally obtained PS4 `.pkg` files and install them from the launcher's **Play** page.

## Highlights

- Full support for `CUSA57767` **1.00 USA** and **1.01 USA** with feature parity across both builds
- Native Vulkan video core derived from shadPS4 with persistent pipeline caching and VRAM fallback
- True Ultrawide Hor+ (`21:9` and `32:9`), configurable render resolutions, SMAA, anisotropic texture filtering, and FSR 1
- Configurable frame rate (`30`–`240` FPS or Unlimited) with drift-free frame pacing
- Automatic / PlayStation / Xbox controller prompts with prepared Xbox button glyphs
- Skip Intro, Title Menu Exit Game, and optional **Unlock Hermes Mode** (off by default)
- Optional **Unlock The Pit Early** (off by default) shows the game's own **The Pit of Agonies** in the title menu before the story is completed; The Pit keeps its original local two-player co-op
- Atomic SaveData with backup/unmount support and full Trophy tracking (`NPWR58134_00`)
- Built-in launcher and self-updater

## Platform Notes

- **Windows x64:** Primary release target. Extract the ZIP to a writable folder and run `sons_of_sparta.exe`.
- **Linux x86_64 AppImage (Experimental):** Built on Ubuntu 20.04 (`glibc 2.31+`) with automatic FUSE / extract-and-run fallback. Linux and Steam Deck live runtime gameplay validation is experimental in v@VERSION@.
